# Cloud Computing Reflection

Cloud computing is part of my everyday life, even if I don’t always notice it. I use three cloud services regularly which are Messenger, Google Drive and Netflix. These apps help me to communicate, store my files and enjoy entertainment anytime as long as I have an internet connection.

Messenger is **Software as a Service (SaaS)** because I only use the app and don't manage the servers or the software behind it. Messenger uses **Public Cloud** because it is available to millions of users worldwide. Google Drive is also **Software as a Service (SaaS)**. I can upload, save and access my files online without the need to install my own storage system. I also consider it a **Public Cloud** service since it's available to anyone with a Google account over the internet. Lastly, Netflix, where I can watch movies and TV shows online through a subscription and it is **Software as a Service (SaaS)**. It is also used via the **Public Cloud** because it is delivering the same service to the users of different countries.

Git and GitHub are also important for cloud computing projects. When many people are working on the same project it is easy to make mistakes or accidentally delete the work of others. Version control records every change made to the project so that older versions can be retrieved if necessary. GitHub provides collaboration where everyone is able to commit changes and see other people’s changes and merge their work in one repository. It also allows you to track who made each change, making it easier to find and fix problems . As a BSIT student, I think it is very useful to learn Git and GitHub because they are commonly used in real software and cloud development projects.
